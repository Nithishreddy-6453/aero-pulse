# Accessibility

- **Keyboard Navigation:** Includes a visually hidden `Skip to main content` link (`sr-only focus:not-sr-only`) targeting `<main id="main-content">` alongside clear focus rings and semantic landmarks.
- **Senior-Friendly Voice Mode:** Native Web Speech API (`SpeechRecognition` input and `speechSynthesis` audio readout) lets seniors listen to verdicts or speak questions hands-free, gracefully hidden if unsupported.
- **Readable Light-Mode Contrast:** Calm Apple HIG Light Mode surfaces preserve high legibility across all AQI atmospheric states.
